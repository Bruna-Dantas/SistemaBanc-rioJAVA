# PROJETO - LP2 - Sistema bancário

Um banco digital em ascensão, o (escolha o nome do seu banco boe), precisa de um sistema de software para gerenciar as contas de seus clientes. O sistema deve ser capaz de criar diferentes tipos de contas, processar transações financeiras básicas (depósito, saque, transferência) e calcular tributos específicos.
<br><br>

## Configuração e Instalação
<br>

1. Clone este repositório em sua máquina local.

```
git clone [https://github.com/<>](https://github.com/Bruna-Dantas/SistemaBanco_Simples.git)
```
<br>

2. Navegue até a pasta do projeto.

```
cd SistemaBanc-rioJAVA
```

<br>

3. Em seguida, execute o comando `javac *.java` e logo em seguida `java Main` no terminal. 

<br>

4. A saída desejada é esta a seguir:

```
========= BANCO DEUS ACUDA =========
1. Criar Conta
2. Realizar Depósito
3. Realizar Saque
4. Realizar Transferência
5. Listar Contas
6. Calcular Total de Tributos
7. Sair
Escolha uma opção:


```

<br>
Discente: Bruna Dantas
